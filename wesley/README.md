# 🔧 Wesley — 首席全能工工作區

## 職責
- 程式測試設計與 QA
- 跨職能支援與協調
- Bug 追蹤與修復紀錄

## 資料夾說明
```
wesley/
├── README.md
├── tests/         # 測試案例與腳本
├── bugs/          # Bug 回報記錄
└── support/       # 跨職能支援產出
```

## 測試命名規範
- 測試腳本：`test_YYYYMMDD_功能名稱.py`
- Bug 回報：`bug_YYYYMMDD_序號.md`

## Bug 嚴重度
- 🔴 BUG-CRITICAL：系統無法運作
- 🟡 BUG-MAJOR：功能異常但可繞過
- 🟢 BUG-MINOR：小問題，不影響主功能
